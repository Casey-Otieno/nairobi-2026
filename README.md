# Hack4Freedom Nairobi 2026

📍 Nairobi, Kenya  
🗓 September 22 – October 5, 2026

Hack4Freedom Nairobi 2026 is part of the Hack4Freedom hackathon series, a women-focused program building open-source freedom technology across the Global South.

This repository is the **central source of truth** for the Nairobi / Kenya 2026 cohort — including program information, resources, and projects built during the hackathon.

Event page: [Hack4Freedom Nairobi 2026 on Evento](https://app.evento.so/e/evt_thLRxQBL9AarUmp3)

---

## About Hack4Freedom Nairobi

Hack4Freedom Nairobi is a **two-week hybrid bootcamp/hackathon** for women developers in Kenya, focused on building open-source tools using **Bitcoin, Lightning, Nostr, and eCash**.

The program combines:
- Education and technical workshops
- Hands-on mentorship
- Public, open-source development

Participants work in teams to build solutions addressing real local challenges, with an emphasis on learning, collaboration, and long-term impact.

---

## Program Structure

### Week 1 — Education & Ideation
- Bitcoin fundamentals and freedom tech context
- Lightning, Nostr, and eCash workshops
- Open-source workflows and GitHub onboarding
- Team formation and problem discovery
- Mentor-led technical sessions

### Week 2 — Building & Mentorship
- Daily stand-ups and progress check-ins
- Mentor office hours
- Focused development sessions
- Project iteration and testing
- Demo Day preparation
