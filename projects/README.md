# Projects

This folder contains summaries and links to projects built during **Hack4Freedom Nairobi 2026**.

Each project is developed by a team of participants as part of the two-week bootcamp/hackathon and is:
- Open-source by default
- Built in public GitHub repositories
- Focused on solving real local problems using Bitcoin and freedom technology

This directory is both a record of the work completed during Hack4Freedom Nairobi / Kenya 2026 and a starting point for continued development after the hackathon.

Project files will appear here as teams open pull requests. There are no project submissions in the catalog yet.
